一个采用 Kotlin 与 Jetpack Compose 编写的非官方第三方 Android 客户端。

## 当前能力

- 原生发现页，读取 NiceCat 公开网页中的真实目录数据
- 发现页仅按手动刷新按钮更新，切换页面不会重复请求
- 真实封面、作品标题、搜索结果和作品详情
- 本地收藏书架，可从详情页收藏并在书架中移除
- 应用内阅读器，支持上滑隐藏标题栏、单击恢复和沉浸式全屏
- 阅读器标题栏使用高对比度文字，长标题自动省略
- 阅读器主动唤醒当前页与下一屏图片加载，减少停在占位页不加载的问题
- 初次确认年龄与条款后保存网站协议 Cookie，避免阅读页重复弹出协议
- 加载状态、错误提示和重试

## 数据边界

项目只读取普通浏览器无需登录即可访问的公开 HTML 与 Nuxt SSR 数据，不包含整站网页套壳，不复制官方 APK，也不绕过登录、付费或服务器安全校验。

阅读器只在应用内承载网站公开阅读页，动态安全校验仍由网站自身执行。目录、搜索、详情和书架均为 Compose 原生界面。

## 构建

```bash
./gradlew testDebugUnitTest assembleDebug
```

GitHub Actions 成功后，可在运行页面的 Artifacts 中下载 `haomao-debug-apk`。
